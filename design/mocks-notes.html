Web pane retro

created 9 Sepedited 2s ago#ui#energy

Shipped in a day. The child webview was the right call; the content-rule compile is slower than expected (~40 s cold) but WebKit caches it, see Energy budget.

  • Shortcuts die inside a focused page. Fixed with a native Go menu.
  • Ad-hoc signed builds re-prompt for Downloads on every rebuild → npm run sign-local
  • The toasts painted under the page until they moved top-right.

  • Live-test section in the spec
  • Runtime list updates (deferred, Notes vault layout depends on the watcher)
